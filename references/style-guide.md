# 风格定制指南 · Style Guide

> 这份文档告诉生成简历的 AI：如何理解用户的"风格提示词"，以及如何优雅地改变一套简历的外观。生成或重写简历时按需查阅。

## 1. 判断用户风格提示词的意图

用户改风格时，可能给图片、形容词、或一整段描述。把它拆成 4 类改动：

| 类别 | 例子 | 对应改动 |
| --- | --- | --- |
| 配色 | "蓝紫渐变""马卡龙撞色""深色科技风" | 改 `:root` 的色变量 |
| 字体 | "无衬线""手写体""未来感粗细对比" | 改 `font-family` 与字重 |
| 布局 | "杂志封面式""单栏条状""卡片式" | 重组区块/网格结构 |
| 质感 | "加噪点""圆角加大""扁平图标感" | 改 radius、背景纹理、border |

## 2. 万能做法：只动 CSS 变量

所有模板的配色、圆角、间距都收敛在 `:root`。绝大多数"换个风格"**只需改这一块**：

```css
:root{
  --primary:...;   /* 主色 */
  --accent:...;    /* 点缀/强调色 */
  --bg:...;        /* 页面背景 */
  --card:...;      /* 卡片背景 */
  --ink:...;       /* 正文文字色 */
  --muted:...;     /* 次要文字色 */
  --line:...;      /* 边框/分割线 */
  --radius:...;    /* 圆角 */
}
```

改动时保持深/浅对比度可读，草稿先给自己读一眼。

## 3. 可复用的风格配方

实际调色时直接套用这些组合：

- **科技感**：`--bg:#0b0f1a`、`--primary:#38bdf8`、`--accent:#a78bfa`，配合霓虹辉光 `box-shadow`。
- **马卡龙撞色**：pink `#ff87ab`、mint `#6de0c1`、lemon `#ffe066`，大面积留白 + 圆角大。
- **杂志封面感**：超大号横排标题、竖排文字 `writing-mode:vertical-rl`、强对比黑白 + 一个强调色。
- **Kindred 手作风**：柔和米白 `#faf6ef`、暖棕 `#8a6d3b`、圆体字、标题加手绘下划线。
- **未来赛博**：荧光青 `#00ffc8` 搭配深紫 `#1a0b2e` 与扫描线纹理。

## 4. 增删区块的原则

- 保留"基本信息 / 经历 / 技能 / 教育 / 作品"这五个主干。
- 创意岗可追加：**获奖、兴趣标签、作品画廊**。
- 删区块时只在用户信息真的没有对应内容时才删；有内容就保留并如实填写。

## 5. 技术约束

- 输出 **HTML**，CSS 全部内联；**不引用任何网络资源**（字体/CDN 一律内联或用系统字体），保证离线可用。图片用同目录的本地文件即可，不要外链。
- 用 `@media print` 控制打印效果，保证能直接导出 PDF。打印的两种模式（默认不带插画底 / `print-with-bg`）见 `background-layer.md` 第 5 节。
- **打印纸张要显式写 `@page{size:A4}`** —— 只写 `margin:0` 会跟随系统默认，在美制默认的机器上静默变成 Letter（612×792pt），而模板的背景图全是 A4 比例。
- **一页装不下时怎么量**：把 `@media print` 临时换成 `@media all`、去掉 `@page`，用无头浏览器读 `.page` 的 `getBoundingClientRect().height`，与 A4 可用高度（1123px 减上下打印 padding）对比 —— 比反复试快得多。**留 40px 以上余量**：`ui-monospace` 这类字体在不同机器上回落不同，字宽一变就多一行。
- 响应式：窄屏（手机）下分栏塌成单栏。
- 改完必须重新输出完整 HTML 文件（不要只给一段 CSS 片段）。

## 6. 插画模式的背景图层

> **只属于插画模式（illustrated）。** 基础模式（basic）不做背景图层，整节跳过。模式界限见 SKILL.md「两种模式」。

背景图层的全部内容 —— 四栏拆解、提示词怎么写与踩过的坑、安全区怎么算、模板元信息什么格式、自检的能力边界、背景怎么接进 HTML 与打印 —— 都在 **`background-layer.md`**，此处不重复。

本节的风格方法论（§1–§5）两种模式通用；插画模式只是在它之上多垫一层背景图。

## 7. 反模板化小技巧

- **对齐出质感**：卡片间距统一用 8 的倍数（8/16/24/32）。
- **一个强调色最多用 2 种**：主色 + 点缀色，其余用灰度。
- **标题不做满**：给标题留白才有高级感。
- **数字视觉化**：经历里的量化成果（增长 3 倍、提升 40%）尽量放大或加粗突出。

## 8. 一寸证件照占位

每套模板都内建一个可点击的证件照上传位（`label.photo`）。使用者点击即可选本地图片，纯前端 `FileReader`/`Blob URL` 预览，不上传网络、离线可用。**改风格时照片位要随风格走，保持同一设计语言**：

| 风格 | 位置 | 形态 | 设计要点 |
| --- | --- | --- | --- |
| serif（极简衬线） | 页眉右上角 | 细边框竖版，悬停变墨蓝 | 与"日期左栏"的克制骨架一致，不加任何装饰 |
| banner（商务横向分区） | 藏蓝横带内右侧 | 白描边框，悬停变哑金 | 压在深色横带上，只有浅色描边才看得见 |
| sidebar（左侧深色侧栏） | 左栏顶部居中 | 浅描边 + 半透明白底 | 深色栏里唯一的浅色元素，自然成为左栏的视觉起点 |
| nouveau（新艺术） | 页眉右下 | **拱形框**（顶角大圆角）+ 金色双描边 | 穆夏海报的标志轮廓；拱形是这份模板的灵魂，改风格时别改成方框 |
| mecha（机甲） | 页眉右侧 | 切角边框（`clip-path`）+ 紫色描边 | 切角呼应整体的棱角语言；整体深色，照片是页眉里唯一的"窗口" |
| editorial（杂志编辑风） | 报头最右 | 1px 黑边方框，悬停降透明度 | 呼应报头的粗黑线，冷峻不俏皮 |

通用规则：
- 保持 `:root` 变量表达配色，**用 `border`/`box-shadow`/`transform` 在风格内做区分**，不要跨风格复制同一套相框样式。
- 证件照适用**纵向 4:3/3:4**（一寸照竖版），框高略大于宽。
- 打印（`@media print`）时：只保留相框与已上传照片，提示文字可用但弱化，确保导出 PDF 干净。
- 若使用者照片是横版/方形且被裁切，`object-fit:cover` 已兜底居中裁切，无需使用者裁剪。
